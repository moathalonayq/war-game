# مسابقة المحينك

لعبة مسابقة جماعية: كل فريق يوزّع جيشه (طائرات/سفن/سيارات) سرًا على شبكة 5×5، ثم يقصف الفرق الأخرى عند الإجابة الصحيحة على الأسئلة.

## التشغيل محليًا
```bash
npm install
cp .env.example .env   # اختياري: عدّل DATABASE_URL إذا توفرت قاعدة بيانات
npm start
```
افتح:
- `http://localhost:3000/admin` — لوحة المدير
- `http://localhost:3000/team` — واجهة الفريق
- `http://localhost:3000/display` — شاشة العرض للجمهور

> إذا لم يتم ضبط `DATABASE_URL` سيعمل بنك الأسئلة في الذاكرة (لن يُحفظ بعد إعادة تشغيل الخادم).

## النشر على Render
هناك ملف `render.yaml` جاهز في المشروع (Blueprint) يُنشئ خدمة الويب وقاعدة بيانات PostgreSQL تلقائيًا معًا.

1. ارفع المشروع إلى مستودع GitHub (خاص أو عام).
2. من [dashboard.render.com](https://dashboard.render.com) اختر **New → Blueprint** واربطه بمستودع GitHub الخاص بك.
3. سيكتشف Render ملف `render.yaml` تلقائيًا وينشئ:
   - خدمة ويب Node باسم `mosabaqa-game` (يشغّل `npm install` ثم `npm start`).
   - قاعدة بيانات PostgreSQL مجانية باسم `mosabaqa-db`، وسيربط متغير `DATABASE_URL` بها تلقائيًا.
4. اضغط **Apply** وانتظر اكتمال البناء (أول نشر قد يستغرق دقيقتين).
5. بعد الانتهاء ستحصل على رابط عام مثل `https://mosabaqa-game.onrender.com` — استخدم:
   - `/admin` للمدير
   - `/team` للفرق
   - `/display` لشاشة العرض

> ملاحظة: الخطة المجانية على Render "تنام" الخدمة بعد فترة خمول، فأول طلب بعد فترة توقف قد يستغرق نصف دقيقة تقريبًا حتى تستيقظ الخدمة. للمسابقات المباشرة يُفضّل فتح الرابط قبل بدء المسابقة بدقيقتين لتنشيط الخدمة، أو الترقية لخطة مدفوعة إن أردت استجابة فورية دائمًا.

### النشر يدويًا بدون Blueprint (بديل)
1. New → Web Service → اربط المستودع.
2. Build Command: `npm install` — Start Command: `npm start`.
3. أضف قاعدة بيانات PostgreSQL من New → PostgreSQL، وانسخ رابط الاتصال (Internal Database URL) إلى متغير البيئة `DATABASE_URL` في خدمة الويب.

## طريقة اللعب
1. المدير ينشئ غرفة من `/admin` ويضيف الفرق (بالاسم).
2. كل فريق يفتح `/team` من جهازه، يدخل كود الغرفة، يختار اسم فريقه، ثم يوزّع جيشه سرًا.
3. عندما تنتهي كل الفرق من التوزيع، يضغط المدير "بدء اللعبة".
4. المدير يعرض الأسئلة من بنك الأسئلة، يحدد من أجاب صح، ثم ينفّذ القصف على الفريق والمربع المطلوبين.
5. شاشة `/display` تعرض تحديثًا لحظيًا لكل الفرق للجمهور.
6. عند الانتهاء، يضغط المدير "إنهاء المباراة" لعرض الترتيب النهائي.
